Saya membuat program yang dapat digunakan untuk menghitung biaya parkir kendaraan berdasarkan jenis kendaraan dan durasi parkir. Dari program ini user akan menginput 3 hal yaitu jenis kendaraan, jam masuk dan jam keluar kendaraan.

Dengan kode ``Function`` yang baru saja dipelajari saya dapat menghitung biayayparkir jika diketahuui jenis kendaraan dan durasi parkirnya. Mobil dikenakan tarif sebesar Rp 5000/jam dan motor dikenakan tarif Rp 3000/jam. User dapat menginput jenis kendaraan, jam masuk dan jam keluarnya. Durasi parkir di hasilkan dari operasi jam keluar dikurang jam masuk.
